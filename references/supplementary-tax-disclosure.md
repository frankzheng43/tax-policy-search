# 上市公司补税公告 — 信息披露框架

## 背景

上市公司补缴税款时，根据《股票上市规则》和实际情况，信息披露的深度不同。常见问题是"公告只写金额不写原因"。

## 两种税务文件 → 两种披露深度

### 1. 《税务行政处罚决定书》→ 必须披露违法事实

触发条件：税务机关认定存在偷税、虚开发票等违法行为，给予罚款。

公告要求：
- 披露违法事实（具体原因、涉及税种、期间）
- 披露处罚金额，对标净资产/净利润10%以上须及时公告
- 需说明是否触及重大违法强制退市情形
- 案例：星星科技（300256）2023年公告——虚开增值税专用发票566份，金额5.3亿，罚款50万

### 2. 《税务处理决定书》/《税务事项通知书》→ 可以不披露原因

触发条件：税务机关要求补税，但不涉及行政处罚。

公告要求：
- 仅披露补缴金额（税款+滞纳金）
- 不涉及行政处罚时，可不披露具体事由
- 案例：爱施德（002416）2026年公告——自查补缴企业所得税1.85亿+滞纳金1.23亿，仅写金额

### 3. 自查补缴（无税务机关介入）→ 最不透明

公司自行发现并补缴，公告通常只写：
- "依据国家税收法律法规的要求，对涉税事项开展自查"
- 补缴金额、不涉及行政处罚
- 不披露具体原因

## 纳税人能从哪里获取具体事由？

| 来源 | 可获取信息 | 获取难度 |
|------|-----------|---------|
| 上市公司公告 | 行政处罚类有具体事实；处理决定类通常无 | 低（巨潮资讯网/交易所网站） |
| 交易所问询函 | 追问具体原因，公司必须回复 | 中（关注深交所/上交所互动易） |
| 税务局公开信息 | 偷逃税典型案例可能公开处理决定书 | 高（各省税务局网站零散） |
| 券商研报/股吧分析 | 推测性分析，非官方 | 低但不可靠 |
| 年报附注 | 可能提及税务风险、关联交易调整 | 中（需等年报披露） |

## 巨潮资讯网 PDF 下载与提取

上市公司公告 PDF 通常托管在：
- `http://static.cninfo.com.cn/finalpage/{日期}/{文件ID}.PDF`
- 搜索结果中 URL 格式如上

提取方法（Python，Android/Termux 环境）：
```python
# 1. 下载 PDF
import subprocess, os
pdf_url = "http://static.cninfo.com.cn/finalpage/2026-06-06/1225356066.PDF"
save_path = os.path.expanduser("~/announcement.pdf")
subprocess.run(["curl", "-sL", pdf_url, "-o", save_path], check=True)

# 2. 提取文本（需 PyPDF2）
from PyPDF2 import PdfReader
reader = PdfReader(save_path)
for page in reader.pages:
    text = page.extract_text()
    if text:
        print(text)
```

**坑：**
- `/tmp` 目录在 Termux 下可能无写入权限，用 `~/` 替代
- `pdftotext`（poppler-utils）在 Termux 可能未安装，PyPDF2 是更可靠的备选
- cninfo 的 PDF URL 格式固定，搜索结果 API 会返回完整 URL

## 滞纳金速算

- 法定滞纳金率：每日万分之五（0.05%/天）
- 滞纳金 ÷ 税款 = 倒推欠税时长
  - 例：爱施德滞纳金1.23亿 ÷ 税款1.85亿 ≈ 67% → 约 3.7 年
- 滞纳金接近或超过税款本金 → 欠税时间很长，风险早有积累
